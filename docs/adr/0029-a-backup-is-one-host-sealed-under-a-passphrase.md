# A Backup is one Host, sealed under a passphrase

Settled by the Owner on 2026-11-06 (#5). `tooob backup NAME FILE` writes one Host's Backup, and `tooob restore NAME FILE` brings it back as Host NAME, on this box or another, so the Site keeps its Key Address and its Visitors when an SD card dies. A Backup holds everything the Host needs to run as it did: its Host Key, `access.json` (Allowlist, Invites, Blocks), `host.json` (the Site and network it last ran with) and its settings file (its Relay). Cookie jars and usage are left out: they're rebuilt.

The passphrase comes from `--passphrase-file PATH`, or `-` for stdin, never from a prompt (ADR 0022) or a `--passphrase` flag, which would leak into shell history and `ps`. Its first line is the passphrase. It's stretched with argon2id (64 MiB, 3 passes, 1 lane: confirmed by the Owner on 2026-11-06, https://github.com/Tooobs/tooob/issues/5#issuecomment-6703328627), and the contents are sealed with XChaCha20-Poly1305, behind a small versioned header: the magic `tooob-backup`, a format version byte (1), the argon2id costs, a 16-byte salt and a 24-byte nonce. The whole header is the cipher's associated data, so a changed cost or salt fails like a wrong passphrase. A Backup's costs travel in its header, so a later Release can raise them and still restore older Backups; `restore` refuses costs above 1 GiB, 16 passes or 16 lanes before running argon2id, so a doctored header can't exhaust or hang a small box before the cipher finds it changed. Only debug builds honour `TOOOB_BACKUP_KIB`, the tests' cheaper memory cost: a Release ignores it.

`restore` decrypts the whole Backup before writing anything, so a wrong passphrase writes nothing. It refuses a Host Name that's taken, as `add` does, refuses while that Host is running, and refuses a Host Key another Host here already has, naming it: it never replaces a Host, and two Hosts never share a Host Key. `backup` replaces a file already at FILE whole: it writes beside it and renames over it, so a failed write leaves the old Backup as it was.

We rejected `age`, which brings its own file format and passphrase handling for what two RustCrypto crates do in a few lines, and `tooob key export/import`, which didn't fit the CLI's `VERB NAME` shape. Backing up every Host at once was rejected too: each Host serves one Site (ADR 0009) and is moved on its own.
