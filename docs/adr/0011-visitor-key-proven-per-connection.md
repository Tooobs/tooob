# The Visitor Key is proven per connection, not used as the connection's key

Each connection to a Host (each browser tab) uses a throwaway iroh key of its own, and its first stream is a hello: the Visitor Key's signature over the protocol, the Host's id and that connection's id. The Host admits by the Visitor Key the hello proves; until then the connection is nobody. We first used the Visitor Key as the iroh key directly, which is simpler, but a Relay keeps one connection per key, so two tabs in one browser knocked each other off. We rejected sharing one connection across tabs (fragile hand-over when the holding tab closes, and the Direct Path would live in one tab) and allowing one tab at a time (limits people). Binding the signature to the connection's id makes a copied hello useless anywhere else, and keeping the Visitor Key out of the transport means it can later move into a non-extractable browser key store.
